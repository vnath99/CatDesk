# T0478 R3B4-C4 — Reviewed candidate launch gate

Date: 2026-10-14. Source-only CLI mode; no installed component, signed release, WakeHost, tunnel or browser mutation.

Added an explicit `--reviewed-candidate-mcp` mode with required `--workspace` source repository, lowercase full `--expected-commit`, process-scoped bearer token, and exact `--host 127.0.0.1 --port 0 --mcp-path /dev/mcp`. It rejects ordinary headless/fixture flags, duplicate and missing options, alternate network scope, weak token and malformed commit. It accepts no caller-selected fixture root, config path, manifest, owner SID or SDDL.

The mode canonicalizes the source workspace and calls `stage_witnessed_candidate_snapshot` before constructing app state or binding a listener. That path requires the live fixed GitHub branch/commit and three-job Windows CI witness, reads only fixed Git objects, creates the owner-only write-ahead snapshot, and returns a pinned manifest and file leases. The runner derives the in-memory fixture app root/config from that exact snapshot, uses the owner-bound isolated router, and binds an ephemeral loopback listener with a non-inheritable socket. It prints only the server-assigned loopback URL, snapshot/commit and redacted bearer metadata. On Ctrl-C it requests bounded graceful shutdown and attempts owner-bound exact-handle retirement; uncertain shutdown or retirement returns an error and must receive operator attention. Journal retirement and durable post-start attention are not yet implemented.

Parser tests pass strict positive and negative cases. A read-only live fail-closed canary against exact source commit `95b88740cd8f6cefdd0846d1026d327dbf2786b6` exited 1 with `GitHub CI for expected commit is missing`, printed no ready URL, and left the counted generated fixture-root population unchanged (12 before and after). This is evidence for the negative witness gate only; no successful reviewed worker launch or normal-stop cleanup has been demonstrated. Full Rust, formatting and Clippy results are recorded in the milestone log.
