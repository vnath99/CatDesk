# T-0485 R6 — Dormant fixed protected install reader

**Scope:** `wake/src/install_broker_reader.rs`, the small read-only fixed-root helpers in `install_broker_preflight.rs`, `validate_manifest` visibility, and the Wake library export. The public selector accepts no path, package ID, pointer or policy from a caller.

The reader first requires the fixed broker preflight, then pins the compiled ProgramData root. It opens `current.json`, `packages`, the selected package, canonical manifest and the four exact artifact names through relative no-follow handles that deny write/delete sharing. It validates exact leaf owner/DACL, type, link count, volume/file IDs, bounded canonical pointer/manifest, exact package inventory, length and SHA-256 of each artifact, and reopens the pointer and inventory before returning. The pointer binds generation, approval ID, predecessor, root, package and manifest objects. Its output is explicitly `READ_ONLY_PROTECTED_PACKAGE_SNAPSHOT_NOT_LAUNCH_AUTHORITY`.

Ten focused Windows tests pass for valid fixed-layout fixtures and rejections of noncanonical pointer, changed physical binding, wrong package/manifest, length/hash tamper, extra or case-changed inventory entries, hardlink/reparse metadata, ACL mismatch and write/rename while the pointer is pinned. All 113 Wake library tests, strict all-target Clippy and formatting passed in the reader implementation review. Independent read-only audit found no concrete bypass in this dormant read path.

**Remaining:** the broker must provision and independently prove the service image, full ancestor effective access/integrity and worker/descendant write denial, protected trust root and completed ledger. The selected pointer must be bound to that ledger and its handles held or rechecked across launch. `start_installed`, status, Binagotchy, recovery and handoff still select the legacy `%LOCALAPPDATA%` pointer, so this snapshot cannot authorize launch, installation, migration or dev.85 acceptance. The old physical store split and exact-source three-job Windows CI also remain unresolved.
