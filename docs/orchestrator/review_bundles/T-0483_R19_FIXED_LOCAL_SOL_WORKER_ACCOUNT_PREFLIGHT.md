# T-0483 R19 — Fixed local Sol worker account preflight (source only)

**Scope:** `src/delegated/sol_worker_identity_preflight.rs` and its Windows-only module declaration. The function is dormant and has no Sol launch, staging, repository, review, or Wake call site.

The zero-argument, read-only `preflight_catdesk_sol_worker_local_account()` checks the fixed `CatDeskSolWorker` account on the local machine. It rejects an unavailable or domain-controller host; reads a bounded `USER_INFO_23` record from the local account database; validates the returned SID within the NetAPI allocation; and reverse-resolves the SID as a user with the exact fixed name in the current local computer domain. It rejects the current host and SYSTEM SIDs, disabled/locked/non-normal accounts, and delegation flags. It then enumerates **all** local groups for the computer-qualified account with `LG_INCLUDE_INDIRECT`, rejecting incomplete or oversized results and membership in the localized built-in Administrators alias. A second account SID/flag readback catches simple replacement races.

The FFI audit bounds the returned NetAPI allocation before reading records, names, or SID bytes, checks SID extent before `IsValidSid`/`GetLengthSid`, caps group counts and string lengths, frees buffers on both success and error, and treats `ERROR_MORE_DATA` as incomplete. The group API's indirect flag includes membership through a global group that belongs to a local group. The computer-qualified query and SID reverse lookup close simple same-name domain aliasing; a domain-controller role is refused because it has no local SAM account domain. [Microsoft's `NetUserGetInfo` and `USER_INFO_23` documentation](https://learn.microsoft.com/en-us/windows/win32/api/lmaccess/nf-lmaccess-netusergetinfo), [local-group enumeration documentation](https://learn.microsoft.com/en-us/windows/win32/api/lmaccess/nf-lmaccess-netusergetlocalgroups), and [SID reverse-lookup documentation](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-lookupaccountsidw) define the queried records and API limits.

**Observed local result:** the fixed-account invocation failed closed with `fixed local account unavailable (2221)` (`NERR_UserNotFound`) on this Windows host. No account was created or altered. This means the live NetUserGetLocalGroups branch could not be exercised against that fixed account here; bounded group fixtures and the API contract were reviewed instead.

**Authority limit:** an account record and current group list are a diagnostic snapshot, not a launch credential or privilege proof. The built-in Administrators alias can be renamed between SID lookup and group enumeration; account membership can change after enumeration, and the second readback checks only user SID/flags. Direct account rights assignments, the actual opened restricted worker token, its groups and privileges, descendant identity/exit, inherited handles, staging ancestors and lost write authority remain unproven. A separate process-bound token check and full lifecycle proof are still required. The Sol workspace-write guard remains closed; no real Sol deliverable or natural review/Wake cycle is accepted.
