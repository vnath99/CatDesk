# T-0485 R12 — One-shot read-only broker service core

**Scope:** `wake/src/install_broker_service_core.rs` and one module export in `wake/src/lib.rs`. This is dormant source. It installs no service, creates no protected package, changes no Wake launch path or install guard, and sends no response to a pipe client. Both production `WAKE_INSTALL_BROKER_UNPROVISIONED` holds remain.

`inspect_one_connected_submission_read_only` takes ownership of a fixed `FixedBrokerPipeEndpoint` and pinned `BrokerProtectedPolicyV1`. It compares the independently pinned policy-root physical identity with the supplied observation **before** request I/O, then calls the existing single-message reader, which checks the sender's connected-pipe token immediately after `ReadFile`. It verifies the canonical detached envelope with the policy's protected Ed25519 key and returns only `BrokerSignatureBindingReadbackV1`. The endpoint is consumed, so this wrapper offers no second-read or retry API.

The returned disposition is `SIGNATURE_AND_SUPPLIED_BINDING_READ_ONLY_NO_INSTALL_AUTHORITY`. The supplied `BrokerObservedStateV1` has not yet been assembled by a fixed service from its own pinned objects and clock. The receipt explicitly lists the still-required trusted clock and predecessor observations, broker-owned exact four-artifact byte inventory, independent exact-source GitHub CI fetch, protected replay/durability ledger, pinned installed-owner proof, and protected pointer/launch-reader plus service bootstrap. No legacy `wake/install.ps1` manifest or caller-computed hash enters this core. A signed manifest shape is not proof of the four candidate file bytes. This module does not call `BrokerLedgerLease::begin` or expose a mutation capability.

**Focused local evidence:** `cargo test --locked --offline --manifest-path wake/Cargo.toml --lib install_broker_service_core` passed 2/2 on Windows. The tests check that the diagnostic omits approval bytes and installation authorization fields while reporting every outstanding gate, and that a wrong physical policy root is refused before any pipe read. `cargo clippy --locked --offline --manifest-path wake/Cargo.toml --all-targets --all-features -- -D warnings` and `cargo fmt --all -- --check` passed locally. These are source tests, not a provisioned SYSTEM-service or positive operator-to-service run.

**Required follow-on:** a separately provisioned fixed service with bounded connect/read deadlines and exclusive pipe-read ownership; broker-owned pinned observations and exact candidate-stage inventory; fixed-origin independent CI fetch; transaction/replay and recovery integration; trusted interactive owner handoff; protected launch-reader cutover; dev.84 physical reconciliation; exact-source three-job Windows CI; and a live Chat53 canary. The status of a read-only signature check cannot be promoted into package approval or install authority.
