# Automatic ordinary development storage advisory

2026-11-04, source qualification. The existing `scripts/catdesk-dev-lane.ps1 build` and `verify` commands now observe reference-volume free space once before their unchanged Cargo commands. No additional opt-in status command is needed. The default warning threshold is 64 GiB; `-StorageWarningFreeBytes 0` disables the automatic query and notice. Other nonnegative thresholds use the existing parameter.

Low free space produces one fixed JSON advisory on stderr. Counter failure produces a fixed unavailable notice; stderr or serialization failure is ignored. Cargo still executes, and its original exit code, exception, environment restoration and location behavior are preserved. The ordinary nine-field stdout receipt is unchanged. `status` performs no automatic query; explicit `storage-status` retains its existing observation semantics, including when its warning threshold is zero.

The advisory reports only fixed categories, free bytes when verified, threshold and non-authoritative scope flags. It exports no workspace path, volume GUID, provider exception or other private content. It reuses the existing three-second local volume query; there is no subtree scan, target-allocation measurement, build admission gate or reinterpretation of benchmark safety gates. Its reference is the source workspace's default target volume; effective inherited Cargo target selection remains unverified. Bare Cargo invocations bypass this facade and its advisory.

Actual public-facade mock tests passed 130 cases on Core and 130 on Desktop without real Git/Cargo, volume queries or build output. Existing compatibility suites passed 36/32 storage cases and 37/37 local-target cases. Their historical whole-source hashes remain unchanged after stripping only the reviewed warning additions and normalization adaptations. The first new test attempt failed because its mock state used the invoked script's scope; the fixture binding was corrected and that failure remains recorded. Evidence: `docs/verification/DEV_LANE_AUTOMATIC_STORAGE_WARNING_2026_11_04.json`.

This is source/test evidence, not installed, live-build or unattended acceptance. No production/Wake change, real build, cache adoption or native fixture was performed. The separately authorized resource-prevention work does not resume the paused general goal. The future output-I/O component remains a separate unfinished dependency.
