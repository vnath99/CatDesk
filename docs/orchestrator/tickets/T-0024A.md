# T-0024A Advisory Broker Primitives

Status: IMPLEMENTED_LOCAL
Date: 2026-07-25
Branch: feature/web-intelligence-advisor

## Objective

Add deterministic, bounded advisory primitives so Qwen can ask for help from a
future stronger web-accessible model without granting that model CatDesk tool
or repository authority.

## Scope Completed

- Added `AdviceRequestV1` and `AdviceResponseV1`.
- Added advisor statuses:
  `READY`, `LOGIN_REQUIRED`, `TAKEOVER_REQUIRED`, `RATE_LIMITED`,
  `UNAVAILABLE`, `TIMED_OUT`, `CANCELLED`, `COMPLETED`, `FAILED`.
- Added `AdvisorAdapter` and deterministic `FakeAdvisor`.
- Added `AdvisorBroker` with disclosure enforcement, redaction, size caps,
  request/result journaling, and untrusted Qwen context output.
- Added trigger gating for explicit Qwen request, two failed bounded repairs,
  and explicitly allowed `NEEDS_SUPERVISOR` advice.
- Added deterministic tests for bounded construction, secret redaction,
  disclosure denial, fake success, timeout/rate-limit status, malformed advice,
  untrusted Qwen handoff, and no direct advisor tool authority.

## Non-Scope

- No SeleniumBase dependency.
- No browser launch.
- No website access.
- No provider replacement.
- No fallback behavior.
- No UI or dashboard.
- No push, PR, merge, release, or deployment.

## Review Notes

Advice is untrusted. Qwen must inspect the repository independently and act
only through ordinary CatDesk tools.
