## Scope Completed

- Enforced local Ollama-only execution at MCP create/validate time:
  `primaryProviderId` must be `ollama`, `fallbackProviderIds` must be empty,
  `allowPaidFallbacks` must be false, and `ollamaBaseUrl` must be loopback
  HTTP with no userinfo or fragment.
- Resolved `localhost` and required it to resolve only to loopback addresses.
- Made one-active-run reservation atomic inside the in-process registry mutex.
- Added a create-new workspace active-run lock at
  `.catdesk/delegated/active-run.lock`; an existing lock fails closed and is
  not treated as recoverable without operator action.
- Released the active-run lock only on known terminal completion or acknowledged
  cancellation.
- Repaired malformed final JSONL event tails before later append while keeping
  malformed non-final records as hard errors.
- Persisted and rehydrated the narrow RunStart approval record:
  approval ID, decision hash, expiry, and consumed state.
- Rejected unsupported free-form acceptance criteria during create/validate.
  V1 supports only bounded verification/test/Cargo and diff criteria.
- Removed model-visible `job.*` tools from the production worker tool surface.
- Removed deferred supervisor operations from MCP `tools/list`.
- Changed startup scripts to pass the MCP token through
  `CATDESK_MCP_AUTH_TOKEN` instead of `--auth-token`.

## Remaining Boundaries

- This remains a local external-MCP-client release candidate. It does not add a
  cloud ChatGPT Web bridge to `127.0.0.1`.
- Only Qwen through local Ollama is active.
- No provider fallback is active.
- One active run per workspace is supported.
- One structured tool call per model turn is supported.
- One file per patch is supported.
- File-journal locking remains intentionally fail-closed after unclean exit
  until explicit stale-lock recovery is designed.
- Pause/steer, browser providers, jobs as model-visible tools, dashboards,
  multi-agent work, automatic commits, push, PR, and merge remain deferred.
