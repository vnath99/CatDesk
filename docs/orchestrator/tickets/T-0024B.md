# T-0024B Browser Advisor Adapter

Status: IMPLEMENTED_LOCAL
Date: 2026-07-25

## Objective

Prototype a standalone browser-backed advisor adapter after T-0024A review.

## Scope Completed

- Added a standalone experimental DeepSeek web advisor adapter.
- Added authenticated JSON Lines stdin/stdout protocol.
- Added selector configuration outside the core adapter logic.
- Added a lazy SeleniumBase CDP launch path with dedicated profile directory.
- Added explicit adapter states:
  `STOPPED`, `STARTING`, `LOGIN_REQUIRED`, `READY`, `SENDING`,
  `WAITING_FOR_RESPONSE`, `COMPLETED`, `RATE_LIMITED`, `TAKEOVER_REQUIRED`,
  `TIMED_OUT`, `CANCELLED`, `DEGRADED`, `FAILED`.
- Added completion detection that combines response-container count, stop/send
  button state, text stability, completion markers, and timeout.
- Added redacted diagnostics.
- Added deterministic offline tests with synthetic HTML fixtures.

## Required Boundaries

- Prefer SeleniumBase CDP mode.
- Use a dedicated persistent browser profile.
- Require manual login.
- Return `TAKEOVER_REQUIRED` for CAPTCHA or security verification.
- Communicate through a narrow authenticated local protocol.
- Expose no repository, filesystem, shell, Git, patch, verification, job, MCP,
  or CatDesk tool authority.

## Explicitly Forbidden

- Plaintext credentials.
- Login automation.
- CAPTCHA-clicking or security-bypass behavior.
- Hard-coded account or conversation data.
- Generated CSS-class selectors as a stable API.
- Infinite keep-alive loops.

## Implementation Status

Implemented as a standalone experimental adapter only. It is not connected to
the CatDesk `AdvisorBroker` or released worker pipeline in T-0024B.
