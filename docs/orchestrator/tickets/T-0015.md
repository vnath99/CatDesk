# T-0015 Context, Compaction, And Efficient Transport

Status: COMPLETED_VERIFIED
Date: 2026-07-25
Branch: orchestrator/v1-coding-sprint
Prior ticket commit: 684e9d2

## Objective

Build deterministic bounded context and provider-neutral handoffs without repeatedly transmitting large files or raw logs.

## Scope Completed

- Added permanent, task-stable, and turn-dynamic context classes.
- Added repository instruction discovery for stable instruction file names.
- Labeled repository instructions and file excerpts as prompt-injection-bearing project content.
- Added ranged file excerpts with containment checks, line limits, and content hashes.
- Added bounded command-output items.
- Avoided resending unchanged command output by replacing duplicates with hash references.
- Added artifact references.
- Added checkpoint summaries.
- Added generic context-budget and provider-limit validation.
- Added explicit local-only versus remote/browser disclosure policy.
- Added compaction that preserves objective, path restrictions, acceptance criteria, current step, failures, and remaining budgets.
- Added byte and simple token estimates.
- Added redacted context-inspection view.
- Added provider-neutral handoff context for replacement providers.
