# T-0017 Patch/Diff Engine And First Disposable Bug Fix

Status: COMPLETED_VERIFIED
Date: 2026-07-25
Branch: orchestrator/v1-coding-sprint
Prior ticket commit: d363555

## Objective

Prove a complete local bug-fix cycle using patch-first edits and authoritative Git diff verification.

## Scope Completed

- Added `PatchProposalV1`.
- Added base and pre-image hash checks.
- Added safe patch preview.
- Added path and scope validation against the execution contract.
- Added patch application through CatDesk-owned file writes.
- Added stale-base rejection.
- Added conflict rejection for missing or ambiguous old text.
- Added patch revision lineage and parent/candidate comparison.
- Added authoritative Git diff artifact capture.
- Added false-success protection so model claims cannot mark verification complete.
- Added deterministic disposable repair-cycle test: bad patch, failing check, revised patch, comparison, passing check, actual diff verification.
- Ran a live Qwen proposal smoke against a tiny disposable excerpt; Qwen returned parseable patch JSON and received no tool authority.
