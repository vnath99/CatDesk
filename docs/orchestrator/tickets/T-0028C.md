# T-0028C: Codex CLI Adapter

## Objective

Add a direct-process adapter for the installed standalone Codex CLI without
connecting it to the released Qwen delegated-worker path. The adapter is a
building block for the later autonomous controller.

## Delivered Boundary

- Runtime capability discovery uses `--version`, `exec --help`, and
  `exec resume --help`; it rejects a missing JSONL, explicit-session, resume,
  or sandbox capability.
- Launches use an explicit direct executable and working directory, with
  argument vectors rather than a shell command string. Batch, PowerShell, and
  command shims are rejected.
- Standard input is closed, stdout and stderr are bounded, diagnostics are
  redacted, and inherited API-key environment names are removed.
- JSONL events capture the Codex thread identifier, expose bounded summaries,
  preserve a cursor, and tolerate unknown event types as non-fatal data.
- Resume requires an already captured thread identifier. The adapter never
  starts a replacement session after a failed resume.
- Cancellation targets only the child process tree created by this adapter.
- A session snapshot contains the captured thread, CLI version, selected
  model, working directory, last completed turn, and event sequence. Durable
  persistence is deliberately deferred to T-0028D.

## Explicit Non-Goals

- No authentication files are read or persisted.
- No API key, authentication token, endpoint, MCP route, or browser state is
  accepted, logged, or stored.
- No Codex turn is routed through the production delegated Qwen runtime in
  this ticket.
- No unsupported CLI flag is inferred. In particular, the installed resume
  help is used as-is rather than assuming a sandbox override exists there.

## Verification

Focused tests cover capability fail-closed behavior, direct-executable
validation, bounded/redacted JSONL parsing, rate-limit classification, and
request validation. The prior T-0028A disposable probe separately established
the installed CLI's real JSONL, thread capture, resume, and owned-process
cancellation behavior.

## Deferred Work

T-0028D persists snapshots and event cursors. T-0028F chooses providers under
an autonomous development contract, applies bounded repair feedback, and owns
rate-limit backoff. T-0028G exposes only policy-safe autonomous controls to
ChatGPT through MCP.
