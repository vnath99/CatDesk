# T-0028G: ChatGPT MCP Interface

T-0028G adds the autonomous-development supervisor schema and durable MCP
control plane. The surface exposes contract creation and validation, approval,
status, cursor-based events, pause/resume/cancel, lease renewal, bounded
escalation retrieval, queue status, and operator-runtime status.

Every state-changing operation requires a session ID, persisted event sequence
as `expectedStateVersion`, and a conservative idempotency key. Replaying the
same key and action is harmless; reusing it for a different action is rejected.
The contract workspace must canonically match the MCP workspace. MCP inputs
never select a Codex executable, script, profile, token, or authentication
source.

`autonomy_session_start` verifies the persisted approval and leaves the session
queued for the CatDesk-owned local runtime. It does not accept an executable,
script path, credential, or transport from MCP. Existing delegated-run
supervisor tools remain unchanged.
