# T-0021 Long-Running Job Manager

Status: COMPLETED_VERIFIED
Date: 2026-07-25
Branch: orchestrator/v1-coding-sprint
Prior ticket commit: 093055f

## Objective

Implement durable process records, bounded log polling, process-tree
cancellation, restart recovery, output rotation, and integration with existing
command policy.

## Scope Completed

- Added `delegated::job_manager`.
- Added durable per-job `record.json` files.
- Added local stdout/stderr log files and one-generation rotation.
- Added bounded cursor-based log polling with truncation and rotation signals.
- Added asynchronous process spawn and terminal-state recording.
- Added process-tree cancellation.
- Added restart recovery that marks missing running processes as `LOST`.
- Reused CatDesk shell safety validation before starting any job.
- Added tests for success, failure, cancellation, lost-process recovery,
  restart, output limits, and command-policy rejection.
