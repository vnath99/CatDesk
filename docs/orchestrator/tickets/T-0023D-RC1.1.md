## Scope Completed

- Worker errors with any `OUTCOME_UNKNOWN` tool call now persist
  `NEEDS_SUPERVISOR` and keep the workspace active-run lock.
- Worker errors without `OUTCOME_UNKNOWN` now persist `FAILED` and release the
  active-run lock.
- Acceptance criteria now use an exact normalized v1 allowlist instead of
  keyword matching.
- Unsupported free-form criteria are rejected during MCP create/validate and
  during completion-gate evaluation.
- Misleading criteria such as `Do not modify tests` are rejected.
- Startup scripts now require explicit non-empty `-AuthToken`.
- Startup scripts pass the token only through `CATDESK_MCP_AUTH_TOKEN`.
- Startup scripts remove `CATDESK_MCP_AUTH_TOKEN` in `finally`.
- Startup scripts do not print or persist the token.
