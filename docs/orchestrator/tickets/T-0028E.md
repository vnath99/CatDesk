# T-0028E: Autonomous Development Contract and Policy

T-0028E adds `AutonomousDevelopmentContractV1` as a distinct schema for the
future ChatGPT Web to Codex autonomous path. It does not alter the released
delegated-run contract or start a Codex process.

The policy engine fails closed:

- the workspace and every allowlisted path are canonicalized;
- existing targets and new paths beneath approved directories are checked
  independently;
- commands must exactly equal a named built-in command profile;
- free-form shell text is rejected;
- force push and main modification are always rejected;
- Codex is the primary provider and Ollama is routine-only, with paid and
  cloud fallback prohibited;
- approvals bind a contract decision hash, expiry, and idempotency key;
- lease validity, renewal permission, and all execution budgets are explicit.

The following controller work will consume this policy before each side effect.
T-0028F will persist approval consumption, evaluate stop conditions, and bind
policy checks to process launch, repair, verification, and recovery.
