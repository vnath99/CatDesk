# T-0028H: Git, Verification, and Artifacts

T-0028H adds the CatDesk-owned local runtime registry and a contract-bound
verifier for autonomous Codex sessions. The runtime reads only the
operator-local `CATDESK_CODEX_CLI_EXECUTABLE` environment variable; MCP
arguments cannot name an executable, script, sandbox, profile, or credential
source. The direct CLI is discovered before use and retains its existing
bounded JSONL, thread-capture, resume, and owned-process cancellation rules.

The verifier checks the contract feature branch, origin, and base-commit
ancestry. It invokes only exact contract-approved verification profiles without
a shell, captures a bounded redacted result, records an authoritative local Git
diff, and emits a final-review artifact only after passing verification and a
diff capture. It never stages, commits, pushes, opens a pull request, or merges.

The runtime registry is process-local. After a CatDesk restart, the persisted
state directs recovery through the captured Codex session identifier; CatDesk
does not silently create a replacement provider session.
