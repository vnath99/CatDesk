# T-0014 Durable Journal And Idempotent Tool Execution

Status: COMPLETED_VERIFIED
Date: 2026-07-25
Branch: orchestrator/v1-coding-sprint
Prior ticket commit: bd29103

## Objective

Persist run, event, tool-call, and patch state so delegated work survives restart without duplicate mutation.

## Scope Completed

- Added a dependency-free JSON/JSONL delegated journal.
- Persisted execution contracts, run snapshots, event cursor state, tool calls, patch proposals, and patch application records.
- Added guarded tool-call lifecycle transitions.
- Rejected duplicate tool-call IDs.
- Rejected duplicate run creation so existing journals are not overwritten.
- Blocked completed tool calls from re-entering execution after restart.
- Blocked `OUTCOME_UNKNOWN` tool calls from replaying without supervisor resolution.
- Preserved patch proposal hashes, application result hashes, and diff artifact IDs.
- Restored active non-terminal runs after reopening the journal.
- Kept journal test state in temporary directories; no database is committed to Git.
