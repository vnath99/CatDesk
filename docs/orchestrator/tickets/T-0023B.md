loop, tightening tool policy and recovery behavior, removing fabricated MCP
supervisor artifacts, and proving the live Qwen flow through the autonomous
worker loop rather than a scripted sequence.

  text-envelope tool calls.
- Added an autonomous `IntegratedDelegatedService` Ollama worker loop.
- Limited production-loop job tools to contracts that actually require jobs.

  failures to `OUTCOME_UNKNOWN`.
- Persisted integrated sidecar state for patch proposals, verification, diff,
  provider history, completed tool calls, and event sequence.

- Recorded patch proposals and applications through the delegated journal.
- Removed fabricated MCP supervisor patch/diff/final-review seed records.
- Changed missing MCP patch/diff/final-review lookups to clear tool errors.
- Added `supervisor-only` headless tool mode for least-privilege startup.
- Fixed and executed local/dev orchestrator startup scripts with disposable
  TOML config paths.
- Added regression tests for durable patch recovery, job containment, failure
  transitions, and supervisor-only MCP behavior.
- Ran the live Qwen production worker-loop closure successfully.
