# Ordinary developer local target: read-only planning

2026-11-04. This sibling facade preserves the existing `catdesk-dev-lane.ps1`, its actions and nine-field receipts. It is not a release, recovery, runtime or cache-management subsystem. The general CatDesk goal remains paused; this source work has separate resource-prevention authorization.

From the source checkout, run `& .\scripts\catdesk-dev-local-target.ps1 plan`. This read-only command proposes a future target below the actual Windows Known Folder LocalAppData: `CatDeskDev\ordinary-targets-v1\<workspace-key>\<recipe-key>\target`. It does not create that location, acquire a writer lease, write a marker, invoke Cargo, adopt an existing target or change configuration. It emits its own versioned JSON; a proposal is not execution authorization.

The Windows metadata adapter opens existing ancestry components with explicit OPEN_NO_RECALL and OPEN_REPARSE_POINT, and retains their handles without delete sharing through observation. Both flags apply to every metadata/data open; there is no fallback. It checks canonical final paths, fixed local volume, physical file IDs, current-user ownership of the workspace/LocalAppData/tool files, and rejects offline/recall/unpinned components. It refuses unexpected Known Folder redirection. Attribute-only inspection precedes data access; tool and lock hashes are read through retained non-writable handles after a second physical identity check. Cargo configuration is checked for existence only; its contents are never read. Unknown configuration or inherited Cargo/tool redirects produce ATTENTION. An already loaded different native adapter template is refused. Reports contain fixed categories and hashed keys, with no absolute paths, owner SID, configuration content or arbitrary exceptions. These are planning checks, not owner-only ACL or complete compiler-runtime provenance qualification.

The workspace key binds physical worktree identity and owner. The candidate recipe key binds cargo.exe, rustc.exe, Cargo.lock, intended host/target, profiles/features and policy. It does not cover compiler DLLs, the linker, the complete toolchain closure or effective build parity; those must be independently qualified before any future execution or reuse. Commit is evidence per observation, not a directory key. A source edit without a candidate recipe change proposes the same namespace. A changed candidate proposes a different namespace but never initializes it. Any existing `CatDeskDev` namespace is HOLD; no owner manifest or historical completion is inferred from its age, PID, unlocked files or a reboot.

## Execution is deliberately unavailable

`build` and `verify` emit a refusal receipt and terminate with `DEVELOPER_TARGET_EXECUTION_OWNER_UNQUALIFIED` before loading the native adapter or manipulating any target. Neither is an executable build path in this version.

The existing ordinary `WakeRepairContainedProcess.Run` returns root exit/timeout information and closes its Job; it does not report whole-Job quiescence plus output EOF/drain. Its process starts before assignment. Those observations cannot support a crash-safe target-reuse OUTCOME. This version does not alter that helper, attach release authority to its result, or manufacture a terminal target record.

Before implementing execution, a separately reviewed ordinary owner must prove suspended-before-assignment containment, explicit fixed executable/environment/cwd, bounded concurrent pipe drainage, whole-Job zero-process completion while owned handles and the target lease remain held, and honest timeout/unknown handling. The target protocol still needs a full-operation exclusive lease, bounded immutable START/OUTCOME, exact selected binary hash binding, refusal of unresolved prior runs, explicit target argv, incremental=0 for both build and verify, and environment/cwd restoration. No existing target may be copied, moved, shared, pruned or silently adopted. No new Cargo home, dependency-cache sharing, global setting or protected-worker change is part of this work.

## Evidence and limits

`scripts/test-catdesk-dev-local-target.ps1` tests pure planning, compatibility keys, privacy, malformed evidence, unknown-namespace HOLD, inherited redirect refusal, public build/verify refusal and complete normalized legacy-source preservation. `-NativeFixtures` additionally creates one tiny unique OS-temp fixture for actual Windows identity/hash/retained-handle/reparse/refusal checks and removes only that fixture after scope validation and handle release. These are not process-lifecycle, target-writer concurrency, crash-reuse or Cargo tests.

The first admitted Core run passed 33 focused cases and 10 native fixture cases. Peer review then caught missing explicit NO_RECALL in the metadata-first refinement. Final corrected Core source passed 34 focused cases and 14 native fixture cases, including both open flag modes and stale adapter refusal; the same facade/test bytes passed 34 focused cases on Windows PowerShell Desktop. Earlier actual read-only planning returned PROPOSED_UNINITIALIZED with no target creation; its exact earlier adapter scope is preserved in `docs/verification/DEV_LOCAL_TARGET_PLAN_SOURCE_2026_11_04.json`. No real Cargo invocation, external target initialization, target migration, installed-runtime qualification or production change follows from these results.
